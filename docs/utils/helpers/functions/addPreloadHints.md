# Function: addPreloadHints()

> **addPreloadHints**(`highlightJsVersion?`, `theme?`): `void`

Inject `<link rel="preload">` hints for critical external resources
(e.g. highlight.js theme CSS). Safe to call multiple times.

## Parameters

### highlightJsVersion?

`string`

The highlight.js version to preload theme for.

### theme?

`string` = `"monokai"`

The highlight.js theme name.

## Returns

`void`
